# RS485_C — 多層樹狀傳感器網路

以 RS485 為傳輸骨幹的**多層樹狀**傳感器資料收集系統。頂層為 PC，往下經多層**中繼器**，末端接各類**傳感器模組**（溫度、壓力…）。最終用於**工廠端即時資料收集**：把傳統 PLC 資料轉為 PC 架構，客戶端可即時讀值、設定條件達成自動控制。

> 本專案接替並取代舊的 `R_C_MOD`。與 `ACL_001`（酒測儀）為完全獨立的兩個項目。

---

## 一分鐘理解

```
PC (頂層, 5V / 未來 Ethernet·WiFi)
 └─ RS485 bus (第1層)
     ├─ 中繼器 1  ── RS485 bus (第2層) ── 傳感器 / 更下層中繼器 …
     ├─ 中繼器 2
     └─ …(單一 bus 最多 64 台)
```

- 每台**中繼器**同時扮演兩個角色：對**上層**是 slave（被要求才回話），對**下層**是 master（主動輪詢）。
- 資料流是「**下層一直輪詢+暫存(cache)，上層要才給**」——把 PC 的讀取速度和下層 bus 速度解耦。
- 每台設備都靠**7 階指撥開關**定址；換機時預載好 JSON、撥同一位址即可直接替換。

## 技術棧

- **末端傳感器模組**：Arduino（C++），單純驅動 + 讀指撥 + 打包傳輸。
- **中繼器**：MicroPython（ESP32），善用 `list`/`dict` 做輪詢佇列與 cache。
- **PC 上位機**：Python（序列埠 / 未來 Ethernet），儀表板 + 規則引擎。
- **RS485 收發器**：MAX13487（AutoDirection，免 DE/RE 方向控制腳）。
