# A. 對外說法（產品簡報三頁）

## A1. 有多簡單：撥一下指撥，就換好了

**標語**：讓你的孤兒 PLC 擴充，不再只是美好的幻想。

模組壞了？拿一台新的、撥成同一個位址、插上線——現場數值馬上回來。

| 步驟 | 動作 | 說明 |
| --- | --- | --- |
| STEP 1 | 撥指撥 | 撥成跟舊機相同的位址 |
| STEP 2 | 插上線 | RS-485 訊號線與電源接回原位，不用拆其他設備 |
| STEP 3 | 自動恢復 | 系統認出位址，自動帶回設定與補償值，數值立即恢復 |

**整個過程：不用電腦・不用軟體・不用編輯設定・不用說明書。**

對照：一般智慧 IO 換一台要「切初始模式 → 接電腦 → 開設定軟體 → 設位址、鮑率、量程 → 切回 → 裝回」。

## A2. 架構：從 PC 一路長成一棵樹

```
PC 上位機
 │  有線：RS-485／乙太網　無線：Wi-Fi
中繼器・第 1 層
 │
═══════════ RS-485 匯流排 ═══════════
 │                              │
中繼器・第 2 層                 中繼器・第 2 層
 │                              ┊
══ 末端匯流排 ══                再往下長更多層
 │    │    │    │
末端 末端 末端 …更多末端
```

- PC 到第一台中繼器：**有線**用 RS-485 或乙太網，**無線**用 Wi-Fi。
- 之後每一層都用 RS-485，層數可依現場往下延伸。
- **末端接在第 2 層（含）以下的中繼器**。
- 每條匯流排都能串多台設備（對外**不寫死數量**，也不提指撥位元分配）。

## A3. 五類現場訊號，我們都讀得到、傳得出

| 類別 | 可接的訊號 |
| --- | --- |
| 類比 | 電壓 0–10 V、電流 4–20 mA、荷重元、應變計 |
| 溫度 | 熱電偶、RTD Pt100、Pt1000、熱敏電阻 |
| 數位／計數 | 開關接點、近接開關、脈衝、編碼器、流量計 |
| 輸出 | 類比輸出、電晶體、繼電器、PWM |
| 串列閘道 | RS-485 儀表、Modbus 感測器、第三方設備 |

**讀值補償**：讀值有偏差也沒關係，送出前可依現場需要先做補償校正，客戶拿到的就是要的數值。（對外不寫補償方式。）

## A4. 對外用語原則

- 拓樸：末端在第 2 層以下；PC 連線寫「有線 RS-485／乙太網、無線 Wi-Fi」。
- 數量：不寫死每條匯流排台數，不提「扣掉功能位」等指撥細節。
- 補償：只說「可補償校正」，不寫 K 值或公式。
- 介面：I2C、SPI、I2S 是板上晶片介面，不對外列為訊號類別。
- 風格：淺色底、活潑、新創感；暖白底＋橘色主色＋柔和色塊。

# B. 內部提案

## B1. 產品摘要

EASY IO 是免設定的分散式遠端 IO：撥好指撥開關、接上 RS-485 線，現場的溫度、壓力、速度訊號就送得到 PLC 或 PC。

- **產品名稱**：EASY IO
- **一句話定位**：讓你的孤兒 PLC 擴充不再只是美好的幻想。
- **核心差異**：用戶不需要用軟體設定。每台設備靠指撥開關定址，壞了換一台、撥同一個位址就恢復運作。
- **通訊協定**：支援 Modbus RTU（RS-485）。Modbus 是「通訊協定」，不是格式或架構。末端模組對外是標準 Modbus slave，PLC 或 SCADA 可直接讀暫存器。
- **訊號類型**：溫度（熱電偶）、壓力（4–20 mA、電壓）、速度與流量（脈衝、編碼器）。透過彈性調整或更換末端模組，可擴充到類比輸出、數位 IO、RTD 等其他訊號，做到全支援。
- **K 值補償**：直讀型感測器的讀數可以在末端依需要補償（單純加減 X + B、線性 AX + B 或其他公式），換算成客戶要的讀值再送出。補償值跟著位址存在型錄裡，換機後自動帶入，不用重校。補償值需與客戶 ON LINE 實測後設定。

## B2. 要解決的問題

工廠裡很多 PLC 還在跑，但原廠擴充模組已停產或很貴，現場要多接幾支傳感器就卡住。我們把這類 PLC 叫做「孤兒 PLC」。

- **擴充卡死**：IO 點數用完，原廠擴充模組買不到或交期長。
- **配線又長又亂**：傳感器散在產線各處，每支都拉類比線回控制櫃，成本高、易受干擾。
- **設定門檻高**：市面遠端 IO 要用專屬軟體設位址、通訊參數、量程；換一台要找會設定的人到場。
- **換機停線久**：模組壞掉時，備品要先上電腦設定才能裝上，產線等人。

## B3. 解決方案與產品架構

EASY IO 由兩種硬體組成：末端模組接傳感器，中繼器把多條 RS-485 匯流排疊成一棵樹，最上層接 PLC 或 PC。架構圖見 A2。

每台設備只靠指撥定址，不需要軟體設定；中繼器把位址逐跳前綴成 `1-2-5` 這樣的完整路徑，所以設備搬到別的分支也不用重配。

- **末端模組**：STM32，接傳感器並換算成工程值；對上是標準 Modbus RTU slave。
- **中繼器**：RP2040，3 個 RS-485 埠（上層、下層骨幹、下層葉段），自己輪詢下層並快取，上層要資料立即回覆。
- **通訊協定**：末端兩側用 Modbus RTU（PLC 與第三方設備都能接）；中繼器之間用自訂高速格式，附 CRC-16 校驗。
- **免設定換機**：中繼器預載設備型錄，看到某位址上線就知道該是什麼設備、推什麼參數。
- **自動終端**：中繼器自己判斷是不是匯流排尾端，自動接上 120 Ω 終端電阻。
- **定址（內部）**：目前 6 位指撥＝5 位位址＋1 位功能位 → 每條匯流排 32 個位址（對外不揭露）。

### 訊號的兩層分類（內部選料用）

**現場訊號**（客戶接線的介面）：類比電壓、類比電流 4–20 mA、熱電偶 mV、電阻（RTD／熱敏電阻）、電橋 mV/V（應變計）、IEPE 振動、數位開關 DI、脈衝／頻率、串列通訊型感測器（RS-485 Modbus、RS-232），以及較少見或新興的 IO-Link、HART、SSI、SDI-12。輸出另有類比輸出、電晶體 DO、繼電器、PWM。

**板上介面**（模組內部晶片之間）：SPI（高精度 ADC、熱電偶晶片、DAC）、I2C（溫濕度、IMU、EEPROM）、I2S（MEMS 麥克風）、UART（接 RS-485 收發器）、GPIO 中斷／計時器（計數、脈衝、DI）。

> I2S 在工業界用於設備內部（例如 MEMS 麥克風做機台聲音異常偵測），不是現場接線用的訊號。工業振動主流是 IEPE 加速度計。

### 末端模組五大類

| 末端板 | 可接的現場訊號 |
| --- | --- |
| 類比板 | 電壓 0–10 V、電流 4–20 mA、荷重元／應變計 |
| 溫度板 | 熱電偶、RTD（Pt100／Pt1000）、熱敏電阻 |
| 數位／計數板 | 開關接點、近接開關、脈衝、編碼器、流量計 |
| 輸出板 | 類比輸出、電晶體、繼電器、PWM |
| 串列閘道板 | 外接 RS-485 Modbus 智慧感測器，之後可擴充 IO-Link |

IEPE 振動需要高取樣率，另列特殊板。

## B4. 競品分析：研華智慧 IO（ADAM 系列）

研華用「一種訊號一個型號」鋪滿產品線，再用同一套 Adam.NET Utility 統一設定所有型號。強在齊全，弱在每一台都要先上電腦設定才能用。

### 產品線

| 系列 | 介面／協定 | 代表型號與訊號 | 官網單價（USD） |
| --- | --- | --- | --- |
| ADAM-4000 | RS-485；Modbus RTU、ASCII 指令 | 4017 8 路電壓／電流、4118 8 路熱電偶、4015 6 路 RTD、4050 16 路 DIO、4060 4 路繼電器、4021 1 路 AO | 141–433 |
| ADAM-6000 | 乙太網；Modbus TCP、HTTP、UDP | 6017 8 AI／2 DO、6015 7 路 RTD、6024 12 路通用 IO、6022 雙迴路 PID | 380–613 |
| WISE-4000 | Wi-Fi、乙太網；RESTful API、內建 HTML5 網頁 | 4050 4 DI／4 DO、4060 4 DI／4 繼電器 | 未查 |

### 研華的設定流程

依研華官方訓練簡報，ADAM-4000 每台上線前要走這四步：

1. 模組切到 INIT（初始模式），同一時間只能一台，此時位址視為 0。
2. 電腦開 Adam.NET Utility，經 COM 埠掃描找到模組。
3. 在軟體裡改位址、鮑率、協定（Modbus 或 ASCII）、資料格式與量程。
4. 切回 Normal，接上匯流排。

ADAM-6000 用同一套軟體以 UDP 廣播搜尋，預設 IP 為 10.0.0.1，要先改 IP 與密碼。換機時備品要重做一次。

### EASY IO 的差異

| 項目 | 研華 ADAM | EASY IO |
| --- | --- | --- |
| 位址設定 | 切 INIT 模式，軟體寫入 | 指撥直接決定 |
| 參數（鮑率、量程） | 每台在軟體裡設 | 中繼器預載型錄，依位址自動推送 |
| 補償與換算 | 校正與工程單位在軟體裡逐台設 | 末端套 K 值補償後送出需要的讀值；K 值存在型錄，換機自動帶入 |
| 換機 | 備品先上電腦設定再裝 | 撥同位址、插上即用 |
| 現場工具 | Windows 電腦、RS-485 轉接器、Utility | 不需要 |
| 拓樸 | 單一匯流排，延伸要加 ADAM-4510 中繼器 | 多層樹狀，中繼器為系統本體 |
| 終端電阻 | 手動加裝 | 中繼器自動判斷尾端並接入 120 Ω |
| 斷線影響 | 整條匯流排 | 只影響該子樹（已實測） |
| 產品線廣度 | AI、AO、DI、DO、RTD、熱電偶、PID 齊全 | 調整或更換末端模組即可全支援，首發先做溫度、壓力、速度 |

研華的「一套軟體設定所有型號」解決的是工程師的設定效率；EASY IO 解決的是「現場沒有會設定的人」。訊號種類上，研華靠多型號覆蓋，EASY IO 靠同一架構換末端模組覆蓋；真正的差異在免設定與換機。研華的優勢主要在品牌。

## B5. 目標客戶與應用場景

客戶分兩群：手上有舊 PLC、沒有專職自動化工程師的中小型工廠；以及監測點多、停機成本高的大型廠，例如半導體廠的廠務系統。

| 客戶 | 痛點 | EASY IO 用法 |
| --- | --- | --- |
| 中小型製造廠 | 舊 PLC IO 不夠、擴充卡停產 | PLC 經 Modbus RTU 讀 EASY IO，新增溫度、壓力點 |
| 設備商／系統整合商 | 每案都要到場設定 IO | 出貨前撥好位址，現場只接線 |
| 廠務維修 | 模組壞了要等人設定 | 備品撥同位址直接換 |
| 數位轉型專案 | PLC 資料上不了 PC | 頂層接 PC 儀表板與規則引擎 |
| 大型半導體廠（廠務、次廠房） | 監測點數龐大、設備世代混雜，模組壞了要等工程師設定 | 多層樹狀一路擴點；故障只影響子樹；備品撥同位址直接換 |

典型場景：烤箱區溫度監控、空壓與液壓管路壓力、輸送帶轉速與流量計；半導體廠的冷卻水、真空幫浦、排氣與供應系統溫壓監測。
