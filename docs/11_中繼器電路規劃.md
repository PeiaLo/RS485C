## 1. 設計定案摘要

| 項目 | 定案 | 理由 |
|---|---|---|
| 埠數 | **3 埠**：UP（slave）、DOWN 主幹、DOWN 葉段（master） | [10 §1–2](10_自動終端與拓樸.md)：主幹快/短、葉段慢/長，各自一條 bus |
| MCU | RP2040 SuperMini；UP=UART0、主幹=UART1、葉段=**PIO UART** | RP2040 只有 2 顆硬體 UART |
| 收發器 | 3× MAX13485E（手動 DE/RE、true fail-safe） | 免偏壓；避免 AutoDir 件 |
| 收發器電壓 | **J6 跳線整台切 3.3V / 5V**（三顆一起切） | 同一條 bus 上每台設一樣，避免混壓掉封包 |
| RO 準位 | 三組固定分壓 **1.5k / 3.6k** | 3.3V 模式 GP≈2.33V、5V 模式（實際 ≤4.7V）GP≈3.3V，兩邊都安全，不用第二個跳線 |
| DOWN 終端 | 固定 120Ω（bus 的頭） | 同一層只有一個往下的，頭端必裝 |
| UP 終端 | **自動**：DET 在位偵測 + TLP3906 光伏驅動 + 2×2N7002 背靠背 + 120Ω | 只有 UP 需要判斷自己是不是尾端 |
| 尾端判斷 | **DET 腳**（不用電流法） | 任何節點都可能插 DC，下游電流可能為 0 或反向，電流法會誤判 |
| 偏壓 | 保留焊盤、**DNP 不上件** | fail-safe 件免偏壓，留作調節手段 |
| 供電 | 任一台可插 DC；VBUS 全樹共用；二極體 OR 防倒灌 | 最少外接電源，電往外送不經二極體 |
| 功耗量測 | 2× INA180A3：**MAX 合計**、**MCU** | 前期評估通訊 vs 運算耗電 |
| 封裝 | 雕刻版可焊：被動 0805（手焊焊盤）、SOIC/SOT-23/DIP/TO-220 | 自製 PCB |

## 2. 電源

### 2.1 架構

```
DC Jack（9–15V）─ F1 ─ D4(TVS) ─ L1 3.3µH ─ U2 降壓模組 ─ 5V_SRC ─┬─ D9 → +5V（本板）
                                                                  └─ D10 → VBUS（分給 bus）
VBUS（J3 腳 1/10，上層/同層共用）─┬─ D1 → R17 → +5V
                                  ├─ F2(PTC) → VBUS_DN1 → J4 ─ D2 → R3 → +5V
                                  └─ F3(PTC) → VBUS_DN2 → J5 ─ D7 → R5 → +5V
+5V ─┬─ R15 → SuperMini 5V 腳 →（板上 LDO）→ 3V3 腳 → R16 → +3V3
     └─ J6 1-2 ┐
+3V3 ─ J6 2-3 ┴─ VCC_SRC → R18 → VCC → U3/U4/U5
```

| 網路 | 意義 |
|---|---|
| 5V_SRC | 本板 DC 經 U2 降壓產生的 5V（**不接受 5V 變壓器**；沒插 DC 的板子由 VBUS 取電） |
| VBUS | 板與板之間共用的電源線，**全樹同一條**，不經二極體穿過本板 |
| VBUS_DN1 / DN2 | DOWN 埠各自經 PTC 隔開的 VBUS；某分支短路只斷那一支 |
| +5V | 本板用電匯流點（D1/D2/D7/D9 OR 而來，約 4.3–4.7V） |
| VCC | 三顆 MAX 的供電（J6 選 3.3V 或 5V） |

### 2.2 保護與重點
- **反接**：D4 為**單向** SMAJ15A，在 F1 之後；插反時 TVS 正偏燒 F1（PTC 可自復）。D3/D4/D5 全用單向件，色帶朝電源側。
- **輸入電壓**：jack 一律經 U2（5.5–32V），但輸入 TVS D4/D5 為 SMAJ15A → **變壓器限 9–15V**。已拿掉原 J2「5V 直入」，高壓不可能灌進 5V_SRC。
- **D3（SMAJ6.0A）**只吸 5V_SRC 上的突波（ESD、插拔尖峰）：5V 下幾乎不漏電，約 6.7V 開始導通；**不是**持續過壓保護。
- **U2 反灌**：D18 陽極 5V_SRC → 陰極 +12V。
- **熱插拔**：C9 100µF 電解在 5V_SRC，撐住插拔瞬間 VBUS 掉壓；各板 +5V 電容維持 10µF 級。
- **VBUS 走線**要扛整個下游電流：雕刻版 J3 → F2/F3 段建議 ≥ 1.5mm。
- **壓降預算**：+5V ≈ VBUS − 0.35V；SuperMini LDO 需 5V 腳 ≥ ~3.6V。24AWG、每台 50mA、每 2m 一台時，一顆 5V 電源放一端約帶 8 台、放中間約 16 台（見討論估算）。

## 3. 各功能與腳位

### 3.1 UP 埠（上層 bus，本機 slave）

| 功能 | 元件 | 連接 → GPIO |
|---|---|---|
| 收發器 | U3 MAX13485E | DI ← **GP0**（TX，UART0） |
| 接收 | RO → R11 1.5k / R12 3.6k | → **GP1**（RX，UART0） |
| 方向 | DE + /RE | ← **GP2**（高=發送） |
| 接頭 | J3（2×5，逆時針編號） | 1/10 VBUS；2/9 A；3/8 B；**4 GND**；**7 DET**；5/6 GND |
| 在位偵測 | J3.7 → R13 10k 上拉 → R14 1k → D11 ESD | → **GP26**（低=下一台已接 → 我不是尾） |
| 自動終端 | GP27 → R10 220Ω → U6 TLP3906 → Q1/Q2 2N7002（源極共接）→ R7 120Ω | **GP27**（TERM_EN，高=投入） |
| 偏壓（DNP） | R8（A→VCC）、R9（B→GND） | 要用時約 470–750Ω |
| ESD | D19（A）、D20（B）、D21（VBUS） | — |

**DET 接法**：左排（1–5）= IN（往上一台）、右排（10–6）= OUT（往同層下一台），兩排各插一條 1×5 線。我的 J3.4 接 GND 讓上一台偵測到我；我的 J3.7 讀下一台的 J3.4。**4 與 7 不可相接**。

### 3.2 DOWN 主幹（往子中繼器，本機 master）

| 功能 | 元件 | 連接 → GPIO |
|---|---|---|
| 收發器 | U4 MAX13485E | DI ← **GP4**（TX，UART1） |
| 接收 | RO → R19 1.5k / R20 3.6k | → **GP5**（RX，UART1） |
| 方向 | DE + /RE | ← **GP3** |
| 接頭 | J4 | 1/10 VBUS_DN1；2/9 A；3/8 B；4–7 GND |
| 終端 | R2 120Ω 固定 | — |
| ESD | D12（V）、D13（A）、D14（B） | — |

### 3.3 DOWN 葉段（往末端，本機 master）

| 功能 | 元件 | 連接 → GPIO |
|---|---|---|
| 收發器 | U5 MAX13485E | DI ← **GP6**（TX，PIO UART） |
| 接收 | RO → R21 1.5k / R22 3.6k | → **GP7**（RX，PIO UART） |
| 方向 | DE + /RE | ← **GP8** |
| 接頭 | J5 | 1/10 VBUS_DN2；2/9 A；3/8 B；4–7 GND |
| 終端 | R4 120Ω 固定 | — |
| ESD | D15（V）、D16（A）、D17（B） | — |

PIO UART 注意：RX FIFO 淺（合併 8 字元，115200 約 0.7ms 滿），MicroPython GC 可能溢位 → 葉段跑低速、或用 `rp2.DMA`；DE 可用 PIO side-set 自動控制。

### 3.4 位址

| 功能 | 元件 | 連接 → GPIO |
|---|---|---|
| 7 位 DIP | SW1 CTS 209-7，腳 8–14 接 GND | 第 1–7 位 → **GP9–GP15**（DIP0–DIP6） |

韌體：`Pin(n, Pin.IN, Pin.PULL_UP)`，等 ~1ms 再讀；ON=0。上電到設定前 RP2040 預設下拉，不會浮空。

### 3.5 功耗量測

| 量測 | 分流 | 放大 → 濾波 | GPIO |
|---|---|---|---|
| **MAX 合計** | R18 0.1Ω（VCC_SRC → VCC） | U7 INA180A3 ×100 → R24 1k / C14 1µF | **GP28**（ADC2） |
| **MCU** | R15 0.1Ω（+5V → SuperMini 5V） | U8 INA180A3 ×100 → R23 1k / C11 1µF | **GP29**（ADC3） |

- 換算：0.1Ω × 100 = **10mV/mA**；滿刻度約 330mA；一格約 0.08mA；取 64 次平均雜訊約 ±0.05mA。
- **J6=5V**：GP28=MAX、GP29=MCU，各自獨立。**J6=3.3V**：MAX 的電也經 SuperMini → MCU = GP29 − GP28。
- 功耗 = 電流 × 標稱電壓（線性電路，電流與輸入電壓無關，故不另量電壓）。
- **量測時拔掉 USB**（USB 會分擔 5V 腳供電）。
- 其餘分流電阻用電錶量兩端電壓（1mV = 10mA）：R17（取自上層）、R3（取自 DOWN 主幹）、R5（取自 DOWN 葉段）、R16（SuperMini 3V3 輸出）。PCB 上兩端留測試點。

## 6. 採購/選料要點

| 料 | 規格 |
|---|---|
| U2 | **78xx 腳位相容降壓模組**，5V 1A、輸入 5.5–32V（取代 L7805：12V 供整條 bus 時 7805 需散 3W 以上）。插在 TO-220 孔位，腳序 1=IN、2=GND、3=OUT，**焊前用電錶確認模組腳序** |
| L1 | 3.3µH 0420 一體成型（約 4.4×4.2mm），Isat 須 ≥ F1 保持電流（封裝 `L_Changjiang_FXL0420`，一般 0420 焊盤相容） |
| F1 | PTC，保持 1.1A、**30V**、1206 |
| F2/F3 | PTC，保持電流依下游分支總量（暫 0.5A）、**30V**、1206 |
| C3、C6 | 25V MLCC（+12V 軌；C6 10µF 用 1206） |
| 其餘電容 | 16V MLCC；**< 10µF 用 0805、≥ 10µF 用 1206**（C5/C6/C7）；C9 100µF 16V 電解（5mm 徑） |
| D3/D4/D5 | **單向** TVS（型號無 C）：D3 = SMAJ6.0A、D4/D5 = SMAJ15A |
| U6 | Toshiba TLP3906（4-pin SO6，本地封裝已放大焊盤） |
| Q1/Q2 | 2N7002（Vgs ±20V）；換料需 Vgs ≥ ±12V、SOT-23 G-S-D |
| 接頭 | 目前 2×5 排針（逆時針編號本地封裝）；杜邦 1×5 **無防呆**，反插會 VBUS/GND 對調 → 考慮換有卡榫的 1×5 |
