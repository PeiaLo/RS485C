# 07 · 採購清單 / BOM（非陸製）

**原則**：晶片產地非中國。ST（歐）、Microchip/TI/ADI（美）、WIZnet（韓）、Semtech（美）、Nordic（挪）、Infineon（德/美）。避開 Espressif(ESP32，中國) 與內含 ESP32 的模組（如 u-blox NINA-W1）。

> 開發板（Blue/Black Pill、UNO 相容板）多為中國組裝但晶片是真的 → **打樣可用；產品走自己的 PCB + 原廠晶片**。Blue Pill F103 常見克隆晶片，產品務必買原廠 ST。

## 手上已有（2026-08-20）

|------|------|------|

| STM32F103 | 2 | C++ 末端（有 ADC+PWM，適合驅動） |

## 要採購

### MCU
| 角色 | 建議料 | 產地 | 備註 |
|------|--------|------|------|
| **中繼器**（MicroPython） | **STM32F411**（Nucleo-F411RE 開發 / F411CEU6） | ST 🇪🇺 | 比 F401 多 RAM(128K)、便宜，MicroPython 首選 |
| 大樹頭層中繼器 | STM32F722/F767 或 **H743** | ST | RAM 256K–1M，多區/大 cache |
| **末端**（C++ 快速驅動） | STM32F103（原廠）/ F401 | ST | ADC+PWM+多 UART |
| 很簡單/5V 末端 | ATmega328（AVR） | Microchip 🇺🇸 | 用共用 lib 的 AVR 版 |

### RS485 / 網路 / 無線
| 品項 | 料號 | 產地 | 備註 |
|------|------|------|------|
| RS485 收發器（主） | **MAX13487EES** | ADI 🇺🇸 | AutoDirection，免 DE/RE。**每末端 1、每中繼器 2** |
| RS485 收發器（二供） | THVD1426（TI）/ THVD1450 | TI 🇺🇸 | 確認方向控制方式（多數 THVD14xx 需 DE/RE GPIO） |
| Ethernet（頂層/跨段，有線首選） | **WIZnet W5500** | WIZnet 🇰🇷 | SPI、內建硬體 TCP/IP |
| 無線（暫緩，若走 LoRa） | **STM32WL** 或 Semtech SX1262 | ST🇪🇺 / Semtech🇺🇸 | STM32WL＝MCU+LoRa 一顆；低頻寬，只適遠端稀疏節點 |
| 無線（若走 WiFi） | Microchip WINC1500 / Infineon CYW43439 | 🇺🇸/🇩🇪 | 需查最新供貨 |

### 被動件 / 其他（每條 bus / 每節點）
| 品項 | 規格 | 說明 |
|------|------|------|
| 終端電阻 | 120Ω ×2/bus | bus 兩端各一 |
| Failsafe 偏壓 | 上拉 A、下拉 B（如 560Ω–1k） | 至少一處，避免閒置浮動 |
| 指撥開關 | 7 位 | 6 位址 + 1 功能 |
| 分壓電阻 | 1k/2k | 5V 節點 TX/RO → 3.3V MCU RX |
| 連接器 | RS485 A/B/GND、電源 | 依板 |
| 燒錄器 | ST-Link | Nucleo 已內建 |

## 自製板（雕刻機）
- 先做**兩層**測試；避免麵包板混亂 → 雕刻機刻板（線寬 > 0.35mm，RS485 低速綽綽有餘）。
- 建議先刻：①末端節點板（MCU + MAX13487 + 指撥 + 接頭）②bus 背板/接線板（含終端+偏壓）。要我出簡單板子的佈局再說。
