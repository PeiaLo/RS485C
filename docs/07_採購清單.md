# 07 · 採購清單 / BOM（非陸製）

**原則**：晶片產地非中國。ST（歐）、Microchip/TI/ADI（美）、WIZnet（韓）、Semtech（美）、Nordic（挪）、Infineon（德/美）。避開 Espressif(ESP32，中國) 與內含 ESP32 的模組（如 u-blox NINA-W1）。

> 開發板（Blue/Black Pill、UNO 相容板）多為中國組裝但晶片是真的 → **打樣可用；產品走自己的 PCB + 原廠晶片**。Blue Pill F103 常見克隆晶片，產品務必買原廠 ST。

## v2 節點硬體增減（vs 舊 DIP 版，2026-10-13）

> 回答「除了 DIP 去掉還要增減什麼」。細節見 [10](10_自動終端與拓樸.md)、[06 §O](06_設計決策與待確認.md)。

**➕ 新增**
| 件 | 用途 | 代價 |
|---|---|---|
| **ENUM 鏈線 + 2 GPIO/節點** | 自動定址枚舉（`ENUM_IN` 讀 / `ENUM_OUT` 驅） | 連接器 +1 pin、2 GPIO |
| **0.1Ω shunt + INA180**（每節點對下游電源線） | 偵測「我是不是尾」→ 自動終端 + 鏈完整性 | ~260µA/台、1 ADC/比較腳 |
| **可切換終端** | 尾端 120Ω 自動投切（THVD1454 內建，或 PhotoMOS+120Ω） | +1 TERM GPIO |
| **連接器加 pin** | in/out 同順序串 A/B/GND/V+/**ENUM** | 連接器升一級 |
| **頭段 adapter（頂層，可插拔）** | WiFi（非陸製 WINC1500/CYW43439）或 W5500 乙太 | 僅頂層 1 顆 |
| **中繼器第 3 收發器/UART** | UP + DOWN-trunk + DOWN-leaf（[10 §1](10_自動終端與拓樸.md)） | RP2040 需 PIO-UART 或改 STM32 多 USART |
| **末端第 2 RS485 收發器** | 尾段 MODBUS master@115200 對外部外設 | 要接外部外設才需 |

**➖ 移除**
| 件 | 原因 |
|---|---|
| **DIP 開關(7位) + 7 GPIO / 74HC165** | 自動定址取代 |
| **固定焊死尾端 120Ω** | 改可切換自動投切（頭端仍固定 120Ω） |
| **偏壓電阻 2×560Ω/bus** | 改 true fail-safe 收發器 → 免偏壓 |
| **分壓電阻 1.8k/3.3k（RO→RX）** | 改 3.3V 原生 fail-safe 件 → 免分壓 |
| **RST 腳** | 軟體重開（記憶 `firmware-soft-reset`） |
| **AutoDir 收發器(MAX13487)** | 改手動 DE/RE fail-safe 件（+1 DE/RE GPIO，但省偏壓） |

**◻ 不影響硬體**：CRC（純軟體、初期不設、後可加）、自動定址枚舉協定（軟體，只需 ENUM 腳）。

> 淨效果：**省掉 DIP/74HC165/偏壓/分壓/固定終端電阻**，**換來 ENUM 1 線 + INA180/可切換終端 + fail-safe 收發器 + 連接器升級**。整體往「自主、免設定、免手調電阻」走，契合 [10](10_自動終端與拓樸.md) 自動終端路線。

## 自製板（雕刻機）
- 先做**兩層**測試；避免麵包板混亂 → 雕刻機刻板（線寬 > 0.35mm，RS485 低速綽綽有餘）。
- 建議先刻：①末端節點板（MCU + 收發器 + INA180/ENUM 自動定址 + 接頭）②bus 背板/接線板（含終端+偏壓）。要我出簡單板子的佈局再說。
