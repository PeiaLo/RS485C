# 07 · 採購清單 / BOM（非陸製）

**原則**：晶片產地非中國。ST（歐）、Microchip/TI/ADI（美）、WIZnet（韓）、Semtech（美）、Nordic（挪）、Infineon（德/美）。避開 Espressif(ESP32，中國) 與內含 ESP32 的模組（如 u-blox NINA-W1）。

> 開發板（Blue/Black Pill、UNO 相容板）多為中國組裝但晶片是真的 → **打樣可用；產品走自己的 PCB + 原廠晶片**。Blue Pill F103 常見克隆晶片，產品務必買原廠 ST。

## 要採購

### MCU
| 角色 | 建議料 | 產地 | 備註 |
|------|--------|------|------|
| **中繼器**（MicroPython） | **RP2040**（YD-RP2040 / Pico 等） | Raspberry Pi 🇬🇧 | **雙 UART**（選它主因）；`dict/json` 用於型錄/hot-swap |
| **高速傳送型中繼器** | RP2040 + **W5500** | 🇬🇧/🇰🇷 | Ethernet 骨幹/頂層 |
| **計算與驅動型中繼器** | Raspberry Pi（Python） | 🇬🇧/🇺🇸 | 複雜多迴路 |
| **末端**（C++，通用） | **STM32F411**（F411CEU6 / Nucleo-F411RE） | ST 🇪🇺 | M4F+FPU、16ch ADC、5V 容忍腳；預設料 |
| 末端（重運算/大 cache） | STM32F7 / **H743** / N6 | ST | M7+cache / DP-FPU+16-bit ADC+雙核 / NPU（見 [08 §3.1](08_末端外設_Driver_韌性架構.md)） |
| 末端（測試/低階） | STM32F103（原廠） | ST | 無 FPU，僅測試用 |

### RS485 / 網路 / 無線
| 品項 | 料號 | 產地 | 備註 |
|------|------|------|------|
| RS485 收發器（現行主用） | **MAX13487EES** | ADI 🇺🇸 | AutoDirection，免 DE/RE，但需偏壓。**每末端 1、每中繼器 2** |
| RS485 收發器（選型建議） | **MAX13485E** / TI **THVD2450**·SN65HVD75 | ADI/TI 🇺🇸 | true fail-safe **免偏壓**（3.3V 件免分壓）；見 [08 §3.2](08_末端外設_Driver_韌性架構.md) |
| RS485 收發器（二供） | THVD1426 / THVD1450 | TI 🇺🇸 | 確認方向控制方式（多數 THVD14xx 需 DE/RE GPIO） |
| Ethernet（頂層/跨段，有線首選） | **WIZnet W5500**（配 RP2040） | WIZnet 🇰🇷 | SPI、內建硬體 TCP/IP |
| 無線（暫緩，若走 LoRa） | **STM32WL** 或 Semtech SX1262 | ST🇪🇺 / Semtech🇺🇸 | STM32WL＝MCU+LoRa 一顆；低頻寬，只適遠端稀疏節點 |

### 被動件 / 其他（每條 bus / 每節點）
| 品項 | 規格 | 說明 |
|------|------|------|
| 終端電阻 | 120Ω ×2/bus | bus 兩端各一 |
| Failsafe 偏壓 | 上拉 A、下拉 B（如 560Ω–1k） | 至少一處，避免閒置浮動 |
| 指撥開關 | 7 位 | 6 位址 + 1 功能 |
| 分壓電阻 | 1k/2k | 5V 節點 TX/RO → 3.3V MCU RX |
| 連接器 | RS485 A/B/GND、電源 | 依板 |
| 燒錄器 | ST-Link | Nucleo 已內建 |

## 自製板（雕刻機）
- 先做**兩層**測試；避免麵包板混亂 → 雕刻機刻板（線寬 > 0.35mm，RS485 低速綽綽有餘）。
- 建議先刻：①末端節點板（MCU + MAX13487 + 指撥 + 接頭）②bus 背板/接線板（含終端+偏壓）。要我出簡單板子的佈局再說。
