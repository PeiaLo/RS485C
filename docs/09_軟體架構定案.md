## 2. 協定分層（線上）

```
第一 byte : 0xFE=核心文字(整條樹) · 1–63/0xFF=MODBUS(只在末端↔外設)
傳輸分層  : 核心=末端→中繼器→PC 全走核心文字 0xFE；MODBUS 只在末端↔外設(尾段 adapter)
位址      : 字串路徑 1-2-3-7（只到節點=自動定址鏈序；外設由節點 cache，不進定址）；逐跳前綴
動詞      : DESC（要說明書）· REQ（要值）· SET（下指令，需 ACK）
編碼      : 核心＝文字格式(§3.2 定案 JSON；提速可換 KV，換了不動中繼器)
轉譯      : 末端吐文字(×1) + PC 轉消費端格式(×1)；中繼器 0 轉譯
完整性    : CRC 可選（初期不設、*<crc> 槽預留、CRC_ENABLED=False；後可加、不影響硬體）
框架外    : age + 健康 envelope(ok/up/rst) → 中繼器純轉發、不碰 payload
```

- **canonical 核心 + 邊界 adapter（2026-11-01 定案，§3.2）**：**整條樹（末端→中繼器→PC）走核心文字格式 `0xFE`**（定案 JSON）；末端**直接吐**、中繼器 **0 轉譯**（只前綴 path + 可選 CRC）。**MODBUS 只在末端↔外部外設**（尾段 adapter，末端=master@115200）；對外互通在 PC 頭段 adapter。
- 私有 frame 範例：`0xFE 1-2-3-7|25.1,3.2,1013*A3F1\r`（node 3 外設值 + CRC；path 到節點）。
- **外設不進定址**：末端 MCU 抓值(外部走 MODBUS)放 cache，descriptor 索引。詳見 [02 §3.1](02_通訊協定.md)、[08 §4](08_末端外設_Driver_韌性架構.md)。

## 3. 資料模型（位址=where、descriptor=what）

- **Node** = 一顆 MCU = 一個 bus 位址（**自動定址給**，ENUM 鏈序；DIP 已拿掉）＝**樹狀定址最深單位**。
- **Peripheral** = node 內一單元，local id = **descriptor 索引**（非 path 段、不進樹狀定址）；外部外設由 node **MODBUS master** 讀進 cache。
- **Descriptor（JSON）**：node 身分 + `peripherals[]`（type / binding〔含 `modbus` 區塊〕 / driver / calibration / measurements）。
- **型錄（catalog）**：所有已知 descriptor 的大 JSON，**預載進中繼器** → hot-swap 靠它（位址 + 型錄 → 知道該位置該是什麼 → 推設定；校正走 per-position）。

## 4. 指標式資料存取（firmware 原則）

**核心：零複製 + 無 heap，資料一律用指標/引用存取（延續 protocol.h/.cpp 的 char-buffer 原則）。**

- **驅動登錄表 = 函式指標表**：`type → {init, read, status}` 函式指標。加新 driver = **加一列指標**，主邏輯不動（無 switch-case 大表、不重編主碼）。
- **外設值槽 = 指標存取**：driver 背景更新自己的值槽；主迴圈打包時**指向**各槽，**不複製**。
- **框架組裝指標化**：REQ 回覆時，按 descriptor 定義的外設順序**逐一指向值槽**串出純值 CSV，免中間 JSON 物件、免暫存大 buffer。
- **AVR/STM32 安全**：char buffer + 指標，不用 `String`/heap（避免碎片、跨板一致）。
- **MicroPython 端對應**：無裸指標 → 原則＝**引用不複製**（cache 存引用、serve 指向 cache 槽、pass-through 不 rebuild payload）。

> 好處：省 RAM、省複製、無 heap 碎片、換編碼/加外設不動主碼。

## 5. 資料流

```
外部外設 ←MODBUS@115200─ 末端(MODBUS master，尾段 adapter) 讀值 → 本地 cache 槽
                        （本地 PID/AI 自主跑，與輪詢解耦）
末端 按 descriptor 把 cache 直接吐成核心文字(JSON) → 0xFE <path>|{json}[*crc]\r
   ↑ 核心文字  中繼器 0 轉譯：前綴自己位址 +（可選）重算 CRC → 存 cache(引用, hold-last)
   ↑ 核心文字  上層要才回 cache（框架外附 age）；快取解耦：PC 照自己速率撈
PC(頭段 adapter) 解析核心文字 → 轉消費端格式 + 儀表板 + 規則引擎（條件觸發 SET 下行, 需 ACK）
```

## 6. 語言 / 平台分工（各取所長）

| 角色 | 平台 | 為什麼 | 分類 |
|---|---|---|---|
| **中繼器** | MicroPython / RP2040 | dict/json 優勢**用在型錄/路由/hot-swap 設定**；傳輸只 pass-through | 純輸送 / 高速傳送 / 計算與驅動 |
| **末端** | C++ / STM32（F411 通用 · F7/H7 重運算） | FPU+ADC+馬達+5V 容忍；driver + 本地 PID/AI | 監控 / 慢控 / 快控 / 輸出 / 安全 |
| **PC** | Python | 排程 + 儀表板 + 規則；對客戶可暴露 MODBUS-TCP | — |
| **board 庫** | C++ / MicroPython | 每 MCU 傳輸 config，換末端只改 `BOARD` 一行 | — |

## 7. 韌性（不冗餘，四道防線）

**預防**（fail-safe 收發器 + TVS/ESD + 隔離 + 焊死）→ **偵測**（CRC + 健康 envelope + 看門狗）→ **優雅降級**（cache hold-last + 本地 PID fail-operational + safe_state）→ **快速復原**（熱插拔 + 溫備 + 型錄自動配置）。頂層中繼器留熱備（故障半徑大）；共享纜線單點先標記。詳見 [08 §9](08_末端外設_Driver_韌性架構.md)、[06 §H](06_設計決策與待確認.md)。
