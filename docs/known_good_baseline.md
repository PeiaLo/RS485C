# RS485_C 電氣接線黃金法則（Electrical Baseline）

**用途**：每條 RS485 bus 的終端 / 偏壓 / 準位規則。佈線或換板時照這個做；訊號不乾淨時第一個回頭對照的就是這裡。

---

## 黃金法則（每條 bus）

> **每條 bus = 2×120Ω 終端（兩端各一，跨 A-B）+ 1 組偏壓（2×560Ω，全 bus 一處）= 共 4 顆。多了少了都錯。**

| 元件 | 正確做法 | 做錯的後果 |
|---|---|---|
| **終端 120Ω** | bus **物理兩端**各一顆，跨 A-B | 只放一端 → 另一端反射；每個節點都放 → 過載、推不動 |
| **偏壓（fail-safe）** | 全 bus **一組** 2×560Ω（A→5V、B→GND） | 沒有 → idle 浮動被誤讀成亂資料；每節點/每 bus 重複 → 拉歪 idle |
| **收發器 /RE** | 接 GND（常收） | 浮空 → 收發方向不定 |
| **極性** | `A↔A`、`B↔B`（USB-485 模組因標示相反，A/B 對調） | A/B 反 → 全 bus 收不到 |

- **USB-485 模組多半內建偏壓** → 它所在那條 bus **不要再外加偏壓**（否則過重）。
- **fail-safe 收發器（MAX13485E / TI THVD2450 等）自帶 true fail-safe** → **免外加偏壓**（見 [08 §3.2](08_末端外設_Driver_韌性架構.md)）。這是選它們的主因。

## 距離 / 速度 / 台數

- **速度 × 距離成反比**：≤90kbps→~1200m、1Mbps→~120m、10Mbps→~12m。
- **一條 bus ≤ 32 個單位負載**（1 UL≈12kΩ）；fractional-UL 收發器（1/4 UL→128 台、1/8 UL→256 台）可增加台數。
- **樹狀 + 中繼器重置**上面兩個限制：每段各自算，總量相加（見 [01](01_系統架構.md)、[08 §7](08_末端外設_Driver_韌性架構.md)）。
- **breadboard 是可靠度天花板**：起步降到 **38400** 買 settle 餘裕；正式佈線一律**焊死**。

## 準位（RO→MCU RX）

| MCU | RO→RX | 原因 |
|---|---|---|
| **RP2040**（非 5V 容忍） | 經分壓 `1.8k/3.3k`（5V→3.24V） | 5V RO 直接接會傷 3.3V 腳 |
| **STM32**（FT 腳 / 3.3V fail-safe 件） | 直接 | FT 腳容忍 5V，或收發器本身就 3.3V |

TX→DI 一律直接。

## 收發器供電特性摸底（2026-09-23，3R3T @115200 短桌面 bus）

把 MAX13487(中繼器) / MAX13485E(末端) **硬降 3.3V 供電（拆掉 RO→RX 分壓）** 實測——兩者都是 5V 件（VCC min ~4.5V），3.3V 屬**超規**。目的：看能不能藉降壓省掉分壓。

| 設定 | 同 bus 電壓一致性 | 樣本(REQ) | 成功率 | 錯誤 |
|---|---|---|---|---|
| 全 5V（基準）| 一致 | ~1098 | 100% | 0 |
| 只 R1 3.3V | 混壓(bus1/2) | 489 | 99.80% | 1（no_reply）|
| R1/R2/R3 3.3V、末端 5V | 混壓(bus2/3/4) | 2316 | 99.957% | 1（no_reply）|
| **全 3.3V（含末端）** | **一致(bus2/3/4)** | 1290 | **100%** | **0** |

**關鍵結論**：
1. **掉封元凶是「混壓」，不是 3.3V 本身**。同一條 bus 上 5V 驅動器與 3.3V 驅動器並存 → 弱驅動方偶爾不達門檻。**電壓一致（全 5V 或全 3.3V）就乾淨。**
2. **13487/13485E 硬降 3.3V「不會燒、短桌面 bus 幾乎無損」**——A/B 腳照 bus 共模範圍設計（與 VCC 無關），5V 驅動不傷 3.3V 供電的件。⚠️ **鐵律：先 VCC→3.3V、確認、再拆分壓**；絕不可出現「5V VCC + 無分壓」（RO 5V 灌非 5V 容忍 MCU → 燒腳）。
3. ⚠️ **仍超規**：3.3V 下絕對驅動較弱、雜訊裕度較低，**短線看不出、長線/高噪/更高 baud 會放大**。開發階段可用；**正式佈線要「3.3V + 免分壓」請換 3.3V 原生 fail-safe 件（THVD2450 / SN65HVD75 / MAX13485 3.3V 版）**，見 [08 §3.2](08_末端外設_Driver_韌性架構.md)、[10 §6](10_自動終端與拓樸.md)。
4. bus1（USB-485 dongle 固定 5V + R1 3.3V）永遠混壓，但短線上仍 0 錯——**dongle 這條混壓可接受**。
