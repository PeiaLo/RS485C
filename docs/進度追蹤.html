已鎖定的決策

廣播保留位址 0（緊急停止用），可用 1–63
CRC先做沒有的，之後再加（框架已預留接口）
協定定版解碼 per-record emit；lib 只做「框架+位址」，REQ/CFG 留韌體
輸出設備暫緩，先把唯讀做穩
末端硬體AVR 5V + MAX13487 直接接；ESP32 的 RO 要分壓
WiFi只用於頂層對PC / 拉不了線的橋接；中間層走 RS485

等你回 / 待討論

  • Stage 0 實機結果 — 先燒 2×ESP32（免分壓），貼 master 監控畫面。
  • MAX13487 數量 — Stage 1（加 UNO 上真 RS485）每台一顆、共需 3 顆。
  • 輸出設備定義 — 你要去討論的（型別、通道、斷線安全狀態）。
  • WiFi 情境 — 目前有沒有跨棟 / 移動設備 / 頻寬爆掉？沒有就先全 RS485。
