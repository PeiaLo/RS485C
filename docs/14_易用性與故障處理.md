# 14 · 易用性賣點與故障處理（整理）

> 本文是使用者口述要點的**忠實整理**，不新增、不延伸。標記：◻＝傾向不做/待定、✗＝明確排除、**需後續延伸**＝之後再展開。
> 整理於 2026-10-14。

---

## 一、便利賣點（面對不同等級使用者，都覺得方便）

### 1. 安裝 / 機構（裝得快、排得整齊）
- **便捷安裝**；或許**適配不同類型背板**
- **專用 BUS 線快速拆裝**
- **對應眾多感測器接口的快接模組**（但也要**防呆**）— **需後續延伸**
  - ◻ **外設腳的編號方式要怎麼記？** — **記下，後面考慮**
- 中繼器與末端**不裝在一起，但都在控制箱內**
- **長寬高其中一個尺寸統一** → 能像 PLC 一樣排在一起
- ◻ 固定方式待定：**快扣**（傾向）vs **螺絲鎖**（比較穩定）

### 2. 換機 / 維運（一個人、免工具）
- **熱插拔**
- **不需螢幕、不需操作**
- 本地**指示燈**做確認：
  - ◻ 待定：**訊號指示燈** vs **定址燈就夠**
  - 燈更新速度慢 → **用 IO 延伸 IC 驅動**
  - 目的：**一個人換完就知道有沒有恢復通訊，不用兩個人配合**

### 3. 防呆
- **要防呆**
- 慢速通訊**跟別人隔開** → **排線不一樣**（不同排線＝不會插錯）
- 感測器快接模組的防呆見第 1 組（**需後續延伸**）

### 4. PC 端
- **即時監控**
- **歷史紀錄**

## 二、故障處理流程（畫面引導、單人、分層）

1. **正常**：看操作畫面即可，沒問題。
2. **異常**：畫面顯示**是哪一個位址的設備**出問題。
3. 先在電腦**對該層 BUS 重置** → 確認結果。
4. **未恢復** → 找出故障設備，**畫面提示要過去更換哪一台**。
5. 範疇：**中繼器 / 末端**＝我方可換模組；**末端外設的傳感器壞 → 由廠方處理（非我方範疇）**。

### 找到設備位置（UI 輔助）
- UI 裡**加參考圖面 / 大致位置示意圖**，才不會找不到。
- ✗ **現場定位先不做**（超出範圍；UWB 有想到但不做）。

### 到操作箱後（看出是哪顆）
- 開箱當下**必須能看出是哪顆出問題**（畫面雖已標出，現場也要對得上）。
- 外殼留**空白面積可以寫編號**（不用貼標籤）。
- ◻ **照明燈**：操作箱常很暗、位置刁鑽——但加照明燈**感覺挺浪費**（傾向不加）。
